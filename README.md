当一个项目同时有多个分支、开发服务、预览页面和编码 Agent 时，真正让人分心的往往不是代码，
而是在窗口之间反复寻找上下文。Troupe 把这些工作集中到同一个空间，让每条开发任务都拥有清晰、
独立且可以随时恢复的工作现场。

## 一块面板，一条工作线

每个 Troupe 面板都围绕一个明确的工作目录展开。你可以横向或纵向拆分终端，为不同功能、分支或
项目保留独立面板，再通过拖拽快速调整布局。当前目录、面板结构和常用选择会被记住，重新打开应用
后可以继续上次的工作。

这很适合同时处理多个开发目标：左侧运行主分支，右侧在工作树中开发新功能；一个面板交给 Agent，
另一个面板保留给人工检查和调试。不同任务彼此隔离，但始终处于同一个视野中。

## 核心体验

### 终端与 Git 在一起

Troupe 会跟随终端当前目录显示仓库和分支状态。常见的分支切换、改动查看、提交历史、合并、变基、
推送、拉取和冲突处理都可以直接完成，不必为了确认仓库状态离开当前工作区。

Git Worktree 是并行工作的核心。你可以从任意分支创建独立工作树，并直接在新的分屏面板中打开它，
让多个功能开发、修复和验证互不干扰。

### 长期任务不再占用工作终端

开发服务器、监听器和其他长期命令可以作为后台任务保存和运行。任务拥有独立输出，支持启动、停止、
重启和搜索；即使切换面板，也能随时看到所有任务的运行状态。

常用的短命令还可以保存为快捷指令，需要时填入当前终端或立即执行。

### 预览就在当前上下文

每个面板都有独立的内置浏览器，可用于访问本地服务、检查页面和跟随开发结果。浏览器以侧边抽屉打开，
无需打断终端布局；收起后页面仍会保留，回来时可以继续之前的操作。

### 与 Agent 一起工作

Troupe 可以汇总本机的 Claude Code 与 Codex 会话，并按项目快速找到和恢复工作上下文。通过 MCP 集成，
Agent 还可以使用内置浏览器、与其他 Agent 交换消息，并在获得授权后操作 SSH 终端。

这让 Agent 不只是一个孤立的命令行进程，而是能够参与当前工作区、理解所属面板并与其他任务协同的
开发伙伴。

### 本地与远程使用同一种方式

保存常用 SSH 连接后，可以直接在独立面板中打开远程终端。远程面板与本地面板共享相同的分屏、任务
和操作体验，同时对 Agent 发起的远程命令保留清晰的授权边界。

Troupe 也可以从当前面板快速打开常用 IDE、系统终端或文件管理器，让现有工具自然融入工作流。

## 适合这些工作场景

- 同时推进多个功能分支、修复或代码审查
- 使用 Git Worktree 隔离不同开发任务
- 一边运行前后端服务，一边查看日志和页面预览
- 同时使用 Claude Code、Codex 或多个编码 Agent
- 在本地项目与 SSH 远程环境之间频繁切换
- 希望减少终端、浏览器、Git 工具和任务窗口之间的来回跳转
